# 💰 کیف پول من — KifPool

اپلیکیشن مدیریت مالی شخصی برای اندروید — کاملاً آفلاین، فارسی و راست‌به‌چپ، با تقویم شمسی، یادآور پرداخت، قفل برنامه و پشتیبان‌گیری.

ساخته‌شده با **Kotlin** و **Jetpack Compose** و دیتابیس **Room**.

---

## ✨ امکانات

### مدیریت مالی
- **داشبورد ماهانه**: مجموع درآمد/هزینه، بودجهٔ ماهانه با نوار پیشرفت و هشدار عبور از بودجه
- **بودجهٔ دسته‌بندی**: سقف ماهانه برای هر دستهٔ هزینه با نوار پیشرفت زنده و هشدار ۸۰٪ (نسخهٔ ۱٫۶)
- **دفتر طلب و بدهی**: ثبت «به من بدهکاره» یا «من بدهکارم» با سررسید شمسی، تسویه و ساخت یادآور — با جمع مطالبات/بدهی‌ها (نسخهٔ ۱٫۶)
- **هدف هفتگی**: پیگیری هزینهٔ هفتهٔ جاری (شنبه تا جمعه) با درصد پیشرفت
- **ثبت درآمد و هزینه**: مبلغ، دسته‌بندی، تاریخ شمسی و یادداشت — با صفحهٔ اختصاصی ویرایش
- **دسته‌بندی‌های سفارشی**: ۱۴ دستهٔ پیش‌فرض + ساخت دستهٔ جدید با ۲۹ آیکون و ۱۲ رنگ
- **تقویم شمسی کامل**: انتخابگر تاریخ جلالی سفارشی، پشتیبانی از سال کبیسه، دکمهٔ «امروز»

### آمار و گزارش
- **نمودار دونات**: سهم هر دسته‌بندی از هزینه‌های ماه
- **نمودار میله‌ای**: روند روزانهٔ هزینه در طول ماه
- **مقایسهٔ ماهانه**: درآمد و هزینهٔ ماه جاری در برابر ماه قبل با درصد رشد/افت

### یادآورها و امنیت
- **یادآور پرداخت**: ثبت مبلغ و روز ماه + ساعت — نوتیفیکیشن خودکار هر روز ساعت ۸:۳۰ و در باز شدن برنامه
- **قفل برنامه**: PIN چهار تا شش رقمی (هش SHA-256) + باز کردن با اثر انگشت (BiometricPrompt)
- **سوال امنیتی**: اگر رمز را فراموش کردی با پاسخ سوال امنیتی وارد شو و رمز جدید بگذار (نسخهٔ ۱٫۶)
- **درخواست مجوز نوتیفیکیشن در اجرا** — سازگار با Android 13+ (بدون کرش)

### داده
- **پشتیبان‌گیری/بازیابی JSON**: خروجی و ورودی کامل همهٔ داده‌ها (تراکنش‌ها + دسته‌ها + تنظیمات)
- **خروجی CSV**: سازگار با اکسل، با BOM برای نمایش صحیح فارسی
- **دادهٔ نمونه**: در اولین اجرا دو ماه دادهٔ واقع‌گرایانه ساخته می‌شود

### ظاهر
- تم تیرهٔ مدرن (سرمه‌ای + فیروزه‌ای نئونی) + تم روشن
- فونت **وزیرمتن**، اعداد فارسی، جداکنندهٔ هزارگان «٬»
- پشتیبانی کامل RTL و ناوبری با نوار پایین + دکمهٔ شناور

## 🚀 ساخت پروژه

**پیش‌نیازها:** Android Studio Ladybug به بالا (یا JDK 17 + SDK 35)

```bash
git clone https://github.com/Pourya-Rezaei/kifpool.git
cd kifpool

# نسخهٔ دیباگ — بدون نیاز به هیچ تنظیم اضافه
./gradlew assembleDebug

# نسخهٔ انتشار — اگر keystore موجود باشد امضاشده، وگرنه unsigned
./gradlew assembleRelease
```

خروجی‌ها در `app/build/outputs/apk/` قرار می‌گیرند.

یا مستقیم در Android Studio: `File → Open` و باز کردن پوشهٔ پروژه، سپس `Build → Build APK(s)`.

## 🔑 امضای نسخهٔ انتشار

به دلایل امنیتی، **فایل keystore در این مخزن عمومی قرار ندارد** و در `.gitignore` مستثنا شده است.

- اگر keystore اختصاصی دارید، آن را در مسیر `app/kifpool-release.keystore` بگذارید — اسکریپت build به‌صورت خودکار آن را شناسایی و نسخهٔ release را امضا می‌کند.
- اگر ندارید، یکی بسازید:

```bash
keytool -genkeypair -v \
  -keystore app/kifpool-release.keystore \
  -alias kifpool -keyalg RSA -keysize 2048 -validity 10000
```

⚠️ نکته: keystore را جایی امن نگه دارید — اگر گم شود، امکان انتشار بروزرسانی روی نسخهٔ نصب‌شدهٔ کاربران وجود ندارد و باید برنامه حذف و دوباره نصب شود.

## 📦 پشتیبان‌گیری و بازیابی

| عمل | مسیر |
|---|---|
| پشتیبان کامل JSON | تنظیمات ← پشتیبان‌گیری داده‌ها |
| بازیابی | تنظیمات ← بازیابی ← انتخاب فایل JSON |
| خروجی CSV | تنظیمات ← خروجی CSV |

فایل JSON شامل همهٔ تراکنش‌ها، دسته‌بندی‌ها و تنظیمات است و هنگام انتقال بین دستگاه‌ها یا نصب مجدد، همه‌چیز را برمی‌گرداند.

## 🗂 ساختار پروژه

```
app/src/main/java/com/kifpool/app/
├── MainActivity.kt          # FragmentActivity + ComposeView + قفل بیومتریک
├── WalletViewModel.kt       # StateFlowها، منطق مالی، پشتیبان‌گیری
├── data/                    # Entityها، DAOها، دیتابیس Room، مدل‌های UI
├── logic/
│   ├── Jalali.kt            # موتور تقویم شمسی (تبدیل، کبیسه، مرزهای ماه)
│   └── ReminderScheduler.kt # ساخت و نمایش نوتیفیکیشن‌های یادآور
├── ui/
│   ├── AppRoot.kt           # ناوبری و مسیریابی (۵ تب: خانه، آمار، دفتر، دسته‌ها، تنظیمات)
│   ├── components/          # نمودارها، دیالوگ‌ها، کامپوننت‌های مشترک
│   └── screens/             # خانه، آمار، دفتر حساب، دسته‌ها، تنظیمات، یادآورها، قفل
├── util/                    # اعداد فارسی، JSON، CSV، پیش‌فرض‌ها، دادهٔ نمونه
└── worker/                  # ReminderWorker — چک روزانهٔ یادآورها (۸:۳۰)
```
